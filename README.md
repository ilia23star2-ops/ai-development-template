# ai-development-template

Шаблон для организации работы ИИ над проектом.

> Кидаешь папку `docs/` в проект → заполняешь → работаешь.
> Правила ИИ — универсальные. Всё проектное — в `PROJECT.md`.

---

## Что внутри
docs/
RULES.md правила работы ИИ (не правится в проекте)
TEMPLATES.md шаблоны проектных доков
PROJECT.md карточка проекта (заполняется один раз)
CONTEXT.md где мы сейчас (обновляется после захода)
PLAN.md роадмап, ветки, техдолг, бэклог
PROGRESS.md история закрытых заходов
DECISIONS.md решения и глоссарий
ISSUES.md открытые проблемы
TESTING.md что и как тестируется

text

---

## Как начать новый проект

1. Скопировать папку `docs/` из этого шаблона в проект.
2. Открыть чат с ИИ, приложить `RULES.md` + `TEMPLATES.md` +
   пустые шаблоны `docs/*.md`.
3. Сказать: «новый проект, помоги заполнить».
4. ИИ задаст вопросы → заполнит `PROJECT.md`, `CONTEXT.md`.
5. Забрать заполненные файлы в проект.
6. Дальше — разработка.

---

## Как работать в проекте

- ИИ читает `RULES.md` + `PROJECT.md` + `CONTEXT.md` + `PLAN.md`.
- После каждого захода — обновляет `CONTEXT`, `PLAN`, `PROGRESS`.
- Идеи «на будущее» — в `PLAN.md`.
- Решения — в `DECISIONS.md`.
- Проблемы — в `ISSUES.md`.

Правила обновления — в `RULES.md`, раздел «Документация».
